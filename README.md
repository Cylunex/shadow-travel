# Shadow Travel

面向个人旅行规划、途中使用与旅行归档的独立应用。

项目以地图为主要交互入口，把一次旅行中的地点、每日行程、路线、照片、笔记、清单和费用组织在一起。首阶段优先满足自用与国内旅行场景，后续再根据实际使用决定是否扩展同行协作、海外地图或公开分享。

## 项目边界

- `shadow-travel` 是独立业务应用，拥有自己的前端、后端、数据库与部署流程。
- `shadow-garden` 继续作为个人门户和内容展示站，只提供旅行应用入口，不承载复杂旅行功能。
- 首版不做旅行社区、攻略交易、酒店机票预订或面向公众的商业化服务。
- 用户创建的行程、照片、笔记与费用数据由自己的服务保存；地图平台只承担地图展示、地点检索、地理编码和路线规划等能力。

## 首版目标

1. 创建和管理旅行，记录目的地、日期、同行人及状态。
2. 按天编排行程，支持地点、时间、停留时长、交通方式和备注。
3. 在地图上搜索、收藏和选择地点，展示每日路线与全部旅行足迹。
4. 保存旅行清单、预算和实际费用。
5. 上传照片并编写旅行笔记，旅行结束后形成可回看的归档。
6. 优先适配手机浏览器，并具备 PWA/离线行程的演进空间。

## 初步技术方向

> 以下是下一阶段设计的起点，不是不可变更的最终方案。

- 后端：Python + FastAPI
- 数据库：PostgreSQL
- 前端：独立 SPA/PWA
- 地图：高德地图 JS API + Web 服务 API
- 图片：文件存储与数据库元数据分离，优先利用自有 NAS
- 部署：独立服务，计划使用 `travel.cylunex.top`
- 鉴权：首版单用户，预留同行协作所需的用户与权限模型

高德个人认证开发者可在个人研究、学习和产品测试阶段使用免费月配额。地图 Key、服务端 Key、域名白名单和调用限额必须分别管理；面向公众运营或商业化前，需要重新核对开发者认证与技术服务许可要求。

## 预期领域模型

- `trips`：旅行主档
- `trip_days`：旅行日程
- `places`：用户选中的地点快照
- `itinerary_items`：按天编排的行程项
- `routes`：交通方式与路线结果
- `checklists`：行前和途中清单
- `expenses`：预算及实际费用
- `notes`：旅行笔记
- `media`：照片与附件元数据
- `companions`：同行人及未来协作关系
